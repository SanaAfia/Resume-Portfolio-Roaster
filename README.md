# Resume-Portfolio-Roaster

A zero-login, browser-based resume analyzer that scores job-description keyword match, flags weak action verbs, and suggests metric-backed bullet upgrades with one-click demo data.

## Run locally

Open `index.html` in a modern browser. The interface uses Tailwind CSS from its CDN, so an internet connection is required for styling.

## Deploy with GitHub Pages

The site is deployed from `index.html` by the workflow in `.github/workflows/pages.yml`. In the repository's **Settings → Pages**, set the build and deployment source to **GitHub Actions**. Each push to `main` then publishes the site at:

https://SanaAfia.github.io/Resume-Portfolio-Roaster/
